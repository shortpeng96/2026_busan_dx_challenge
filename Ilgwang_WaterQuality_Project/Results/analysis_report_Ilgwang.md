# 🌊 일광 해수욕장 수질 AI 예측 모델 — 데이터 분석 과정 정리

## 1. 프로젝트 개요

| 항목 | 내용 |
|---|---|
| **해수욕장** | 일광 해수욕장 (부산 기장군) |
| **목표** | 수질 기준 초과(입수 통제) 여부를 사전 예측하는 AI 분류 모델 개발 |
| **최종 성능** | ROC-AUC **0.818** (5-Fold 교차 검증) |

## 2. 데이터 탐색 및 라벨링 수정

### 2-1. 초기 문제 발견
- 원본 수질 데이터(292건 raw records)에서 대장균(E.coli ≥ 500 CFU) 기준만 적용 시 양성 31건, 장구균(Enterococcus ≥ 200) 기준만 적용 시 양성 25건
- 그러나 일별 집계 후 실제 모델에 들어가는 레코드는 **81건**에 불과 (다중 지점 검사 → 일별 최댓값 집계)
- 기존 일광 모델(이전 파이프라인)은 `distance_from_estuary_km` 등 하드코딩된 피처 15개를 사용했으나, **오차 분석(error_analysis_dump.csv)에서 전체 129건이 모두 오류**로 판별 → 모델이 제대로 작동하지 않았음

### 2-2. 라벨링 기준 재정립
- 임랑 해수욕장에서 성공한 복합 라벨링 전략을 일광에도 적용
- 라벨링 기준: `E.coli ≥ 500 OR Enterococcus ≥ 200`
- **양성 샘플: 20건 (24.7%)** — 통계적으로 의미 있는 학습 가능한 수준

> [!IMPORTANT]
> 기존 일광 모델은 피처 엔지니어링과 라벨링 모두에 문제가 있었습니다. 임랑에서 검증된 파이프라인을 이식하여 근본적으로 재구축했습니다.

### 3-4. 전체 가용 외부 데이터 통합
| 데이터 | 출처 | 핵심 변수 |
|---|---|---|
| 정밀 조위 | 국립해양조사원 | 조차(tide_range), 1일 전 조차 |

| 정밀 풍향/풍속 | 기상청 AWS | 풍향(sin/cos 변환), 1일 전 풍향 |

- 총 피처 수: **102개** (기상 + 부이×2 + 방류량 + 조위 + 수온 + 풍향)
- RFE(Recursive Feature Elimination)가 102개 중 **9개 핵심 피처** 자동 선별

## 4. 모델링 기법 (단계별)

### 4-1. 기존 일광 모델의 한계
```
기존 파이프라인 (이전 버전)
├── 하드코딩된 15개 피처 (BEST_FEATS 고정)
├── XGBRegressor 단일 모델
├── SMOTE 미적용
├── Optuna 미적용
└── 결과: error_analysis_dump.csv 전 건 오류 → 사실상 작동 불가
```

### 4-2. 새 파이프라인 (임랑 파이프라인 이식)
```
┌─────────────────────────────────────┐
│         Dual Ensemble 구조          │
├──────────────┬──────────────────────┤
│  Classifier  │  XGBClassifier       │ ← AUC / 경보 판단용
│  (분류기)    │  + RandomForest      │
├──────────────┼──────────────────────┤
│  Regressor   │  XGBRegressor        │ ← UI 시계열 차트용
│  (회귀기)    │  + RandomForest      │
└──────────────┴──────────────────────┘
```

### 4-3. SMOTE 양성 샘플 증강
- 20건밖에 없는 양성(초과) 샘플을 **SMOTE(Synthetic Minority Over-sampling Technique)**로 합성 증강
- **핵심 원칙**: 학습(Train) 폴드에서만 증강하고, 평가(Test) 폴드에는 절대 가짜 데이터를 섞지 않음 → AUC 신뢰성 보장
- `k_neighbors=3` (양성 20건 기준 최적값)

### 4-4. RFE 자동 피처 선별
- 102개 후보 피처에서 5→102 범위로 탐색하여 **AUC가 가장 높은 9개** 자동 선별
- RFE 단계 AUC: **0.773**

### 4-5. Optuna 하이퍼파라미터 자동 최적화 (AUC 0.773 → 0.818) ✅
- **100회 Trial** 자동 탐색 (TPE Sampler)
- 탐색 대상 파라미터:

| 모델 | 파라미터 | 탐색 범위 |
|---|---|---|
| XGBoost | 학습률 | 0.01 ~ 0.3 (log) |
| XGBoost | 트리 깊이 | 2 ~ 8 |
| XGBoost | 트리 수 | 50 ~ 800 |
| XGBoost | 서브샘플링 | 0.5 ~ 1.0 |
| XGBoost | L1/L2 정규화 | 0.001 ~ 10.0 |
| RandomForest | 트리 수 | 50 ~ 500 |
| RandomForest | 깊이 | 3 ~ 12 |
| RandomForest | 최소 리프 샘플 | 1 ~ 10 |
| 앙상블 | XGB 가중치 | 0.3 ~ 0.8 |

- 최종 앙상블 가중치: XGBoost **78.7%** + RandomForest **21.3%**

## 6. 최종 모델이 선택한 핵심 9개 변수

| 순위 | 변수명 | 의미 | 도메인 해석 |
|---|---|---|---|
| 1 | `gijang_수온(℃)_7d_mean` | 기장 부이 7일 평균 수온 | 수온 상승 → 세균 번식 촉진 → 오염 확률 증가 |
| 2 | `precip_3d_sum_lag` | 3일 누적 강수량 (1일 지연) | 연속 강우 → 지표·하수 오염물질 해안 유입 |
| 3 | `gijang_기압(hPa)_7d_mean` | 기장 부이 7일 평균 기압 | 저기압 → 비/태풍 동반 → 오염 유입 증가 |
| 4 | `temp_daily` | 당일 기온 | 고온 → 세균 활성화, 여름철 오염 집중 |
| 5 | `meis_최대파고(m)_3d_mean` | 울산 부이 3일 평균 최대파고 | 높은 파고 → 해저 퇴적물 교란 → 대장균 재부유 |
| 6 | `meis_기압(hPa)_7d_mean` | 울산 부이 7일 평균 기압 | 광역 기상 패턴(저기압 접근) 감지 |
| 7 | `gijang_풍속(m/s)_1d_lag` | 기장 부이 전일 풍속 | 강풍 → 해수 혼합 → 오염물질 확산 |
| 8 | `gijang_최대파고(m)_3d_mean` | 기장 부이 3일 평균 최대파고 | 근해 파고 → 연안 오염물질 유입 강도 |
| 9 | `meis_기온(℃)_1d_lag` | 울산 부이 전일 기온 | 광역 기온 변화 → 오염 패턴 변동 |

> [!NOTE]
> **9개 변수 모두 해양환경학적으로 타당한 변수**입니다. 특히 임랑(내륙 강수·방류량 중심)과 달리 일광은 **해양 부이 데이터(수온·파고·기압)**가 지배적인 것이 특징입니다. 이는 일광이 동해안 개방형 해수욕장이라 해양 조건의 영향을 더 직접적으로 받기 때문입니다.

## 10. 교훈 및 시사점

1. **파이프라인 이식의 위력**: 임랑에서 검증된 파이프라인(복합 라벨링 + RFE + SMOTE + Optuna)을 일광에 그대로 이식한 결과, 기존 전 건 오류 모델이 **AUC 0.818**로 극적으로 개선됨
2. **해수욕장마다 다른 핵심 변수**: 임랑은 강수·방류량, 일광은 해양 부이(수온·파고) — 동일 알고리즘이 지역 특성을 자동으로 학습
3. **RFE 자동 선별의 중요성**: 102개 피처 중 9개만으로 최고 성능 → 하드코딩된 피처 목록은 오히려 성능을 악화시킴
4. **SMOTE의 효과**: 20건의 양성 샘플만으로도 증강 기법을 통해 안정적인 학습 가능
5. **Optuna가 마지막 벽을 돌파**: RFE AUC 0.773 → Optuna 최적화 후 **0.818** (+0.045)
