# 🌊 2026 부산 해수욕장 수질 AI 예측 입수 통제 모델 (2026 Busan DX Challenge)

본 레포지토리는 2026년 부산디지털혁신(DX) 챌린지 - "해수욕장 수질 AI 예측 입수 통제 시스템" 구축을 위한 전체 데이터 파이프라인과 모델을 포함하고 있습니다.
본 저장소 하나만 복제(Clone)하더라도 7개 해수욕장의 전체 데이터 분석, 모델 학습 및 결과물 재생성이 가능하도록 독립적(Self-contained)으로 구성되었습니다.

## 📌 1. 프로젝트 개요 (Project Overview)
본 프로젝트는 부산광역시 주요 7개 해수욕장의 대장균(E.coli) 및 장구균(Enterococcus) 수질 오염을 선제적으로 예측하고, 데이터 기반의 입수 통제(Dual-Threshold) 경보 시스템을 구축하는 것을 목표로 합니다.
과잉 통제로 인한 지역 상권 피해를 최소화하면서도 시민의 안전을 지키기 위해, **해수욕장별 지형적 특성과 주요 오염원에 맞춘 개별 특화 AI 모델**을 개발했습니다.

---

## 🏗️ 2. AI 아키텍처 요약 (Architecture Summary)
각 해수욕장의 수질 변동성 및 데이터 특성에 맞추어 두 가지 형태의 맞춤형 아키텍처를 채택했습니다.

| 아키텍처 타입 | 적용 해수욕장 | 특징 (Key Features) |
| :--- | :--- | :--- |
| **순수 회귀(Regressor) 기반** | **다대포, 해운대, 광안리** | 회귀기가 오염 농도를 직접 예측(Continuous Value)하고, 이를 바탕으로 통제 점수까지 직접 환산하는 방식. |
| **듀얼 앙상블(Dual-Ensemble) 기반** | **송도, 송정, 일광, 임랑** | 통제 알람(임계값 판별)은 분류기(Classifier)가 전담하여 오탐을 강력히 방어하고, 대시보드 시계열 그래프용 곡선은 보조 회귀기(Regressor)가 그리는 투잡 시스템. |

---

## 🏖️ 3. 해수욕장 모델 그룹화 (Beach Grouping by Features)

해수욕장마다 오염의 원인(강, 바다, 날씨 등)이 다르기 때문에, 모델에 사용된 **핵심 피처(변수)**를 기준으로 3개의 그룹으로 분류하여 설계했습니다.

### 🌊 그룹 A: 하천 방류 및 하수 유입 특화 (River & CSO)
대형 강이나 지역 하천에서 유입되는 담수와 강우 시 하수처리장(CSO)의 월류가 수질에 절대적인 영향을 미치는 그룹입니다.
* **다대포 해수욕장 (Dadaepo)**
  * **핵심 피처**: 낙동강 하구둑 방류량(10문/15문), 다대 CSO 펌프장 가동 수위.
  * **특징**: 서측/동측 해변을 분리하여 CSO 플래그(95백분위수 임계값)를 독립적으로 적용.
* **일광 해수욕장 (Ilgwang)**
  * **핵심 피처**: 일광천 등 지역 소규모 하천의 수위 및 방류량.
  * **특징**: 만(Bay) 형태로 갇혀 있어 지역 하천을 통한 담수 유입 민감도가 매우 높음.

### 🛰️ 그룹 B: 외해 파랑 및 해양 부이 특화 (Offshore & Buoy)
외해에서 밀려오는 해류, 파랑, 바람의 방향이 오염 물질을 해안가로 밀어붙이는 현상이 중요한 그룹입니다.
* **해운대 해수욕장 (Haeundae)**
  * **핵심 피처**: 해운대 앞바다 해양 관측 부이(파고, 풍속, 풍향).
* **광안리 해수욕장 (Gwangalli)**
  * **핵심 피처**: 수영만 인근 해양 부이 데이터 + **체류 인구(방문객 수)** 결합.
  * **특징**: 도심 밀착형 해변으로, 유일하게 사람에 의한 변수(방문객 수)를 추가 파이프라인으로 구성.
* **임랑 해수욕장 (Imrang)**
  * **핵심 피처**: 고리/기장 원전 인근 해양 관측 부이 데이터.
  * **특징**: 상징성과 안전 최우선을 고려하여 통제 임계값을 가장 보수적으로 튜닝.

### ☁️ 그룹 C: 국지 기상 및 지형 고립 특화 (Local Weather & Topography)
특정 지역에만 쏟아지는 국지성 호우나 바람, 지형적 고립으로 인해 발생하는 극단적 수질 변화를 겪는 그룹입니다.
* **송도 해수욕장 (Songdo)**
  * **핵심 피처**: 서부산권 로컬 전용 국지 강우 및 기상청(ASOS) 데이터.
* **송정 해수욕장 (Songjeong)**
  * **핵심 피처**: 송정 전용 국지 기상 데이터.
  * **특징**: 평소 수질이 매우 맑아 오염 데이터가 극히 적은 한계를 극복하기 위해 **SMOTE(오버샘플링)** 기법을 활용한 클래스 불균형(Class Imbalance) 해소 기술 적용.

## 🚀 4. 시작하기 (How to Run)

### 4.1. 환경 설정
필요한 패키지를 설치합니다. Python 3.9+ 이상의 환경을 권장합니다.
```bash
pip install -r requirements.txt
```

### 4.2. 스크립트 실행 순서
각 해수욕장의 `Scripts/` 폴더 내에 있는 3개의 파일을 순차적으로 실행하면 됩니다.
예를 들어, **다대포 해수욕장**의 파이프라인을 실행하려면 다음과 같이 진행합니다:

```bash
cd 2026_busan_dx_challenge/Dadaepo_WaterQuality_Project/Scripts

# 1) 원시 데이터를 가공하여 master_dataset.csv 생성
python 01_preprocess.py

# 2) 전처리된 데이터로 모델 학습 후 Results 폴더에 pkl 저장
python 02_model.py

# 3) 엔터프라이즈 마크다운 리포트 및 시각화 도표 생성
python 03_generate_results.py
```
> 스크립트가 성공적으로 완료되면 각 해수욕장의 `Results/` 폴더 내에 `analysis_report_[해수욕장명].md` 파일과 주요 시각화 차트들이 렌더링됩니다.

## 📁 5. 디렉토리 구조 (Directory Structure)
각 해수욕장별로 프로젝트 폴더(`[Beach]_WaterQuality_Project`)가 독립적으로 존재하며, 내부 구조는 모두 다음과 같이 일원화되어 있습니다.

```
2026_busan_dx_challenge/
├── README.md                      ← 본 문서
├── requirements.txt               ← 필요 라이브러리 목록
├── Scripts/                       ← 공통 헬퍼 스크립트 모음
├── [해수욕장명]_WaterQuality_Project/
│   ├── Data_Raw/                  ← 외부 수집 원시 데이터 (해양부이, 기상청, 수질관측 등)
│   ├── Data_Processed/            ← 01_preprocess.py에 의해 생성되는 최종 학습용 CSV
│   │   └── master_dataset.csv
│   ├── Scripts/                   ← 실행 스크립트 모음 (순차 실행)
│   │   ├── 01_preprocess.py       ← 데이터 전처리 및 병합
│   │   ├── 02_model.py            ← AI 예측 모델 학습 (XGBoost)
│   │   └── 03_generate_results.py ← 마크다운 결과 리포트 및 시각화 도표 생성
│   └── Results/                   ← 학습된 모델(pkl), 성과 리포트(md), 그래프 이미지(png)
```
