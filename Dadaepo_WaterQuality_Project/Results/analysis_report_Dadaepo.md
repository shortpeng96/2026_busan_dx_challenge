# 🌊 다대포 해수욕장 수질 AI 예측 모델 — 데이터 분석 과정 정리

## 1. 프로젝트 개요

| 항목 | 내용 |
|---|---|
| **해수욕장** | 다대포 해수욕장 (부산 사하구) |
| **목표** | 수질 기준 초과(입수 통제) 여부를 사전 예측하는 AI 모델 개발 |
| **최종 성능** | ROC-AUC **0.946** (5-Fold 교차 검증) |
| **데이터 규모** | 305건 수질 검사 기록 (2015~2026), 양성(초과) 46건 (15.1%) |

---

## 2. 지역적 특성과 문제 정의

### 2-1. 낙동강 하구라는 지리적 특성
- 다대포 해수욕장은 **낙동강 하굿둑과 물리적 거리가 0에 가깝게 인접**해 있습니다.
- 따라서 내륙에서 발생한 집중 호우가 낙동강을 통해 대량의 담수와 오염물질을 해수욕장으로 밀어내는 '하천 유입형 오염'의 직격탄을 맞는 곳입니다.

### 2-2. 결측치(Missing Values) 처리의 난관
- 낙동강 하굿둑 방류량 데이터나 연안 수질 측정망(센서) 데이터에는 결측치가 다수 존재했습니다.
- 단순 결측치 제거(Dropna) 시, 가용 데이터가 **305건에서 21건으로 93% 이상 증발**하는 치명적 문제가 발생했습니다.

---

## 3. 데이터 통합 및 고급 피처 엔지니어링 (V2)

결측치 문제를 해결하고 다대포만의 하천 유입 특성을 살리기 위해 다음과 같이 데이터를 구성했습니다.

### 3-1. 다중 소스 데이터 결합
| 데이터 | 출처 | 결합 방식 |
|---|---|---|
| 수질 검사 | 해수부 | 날짜 기준 기본 (대장균, 장구균) |
| 기상 관측 | 기상청 (부산 159) | 1일전, 3일 누적 강수량/기온/풍속 래그(Lag) |
| 수질 센서 | 낙동강 하구 환경센서 | 염도, 탁도, 수온 (결측치 다수 존재) |
| 하수 방류량 | 부산환경공단 (강변/장림) | 1일전 및 3일 누적 방류량 (sewage_discharge) |
| 하굿둑 방류 | K-water 낙동강통합물관리 | 낙동강 하굿둑 방류량 (discharge_volume) |

### 3-2. `IterativeImputer` 기반 결측치 머신러닝 복원
- 결측치로 인해 버려지던 280여 건의 소중한 데이터를 구출하기 위해 `IterativeImputer` 알고리즘을 도입했습니다.
- `RandomForestRegressor`를 내부 추정기로 사용하여, 기상/방류량 등 다른 멀쩡한 변수들의 패턴을 학습해 **결측된 센서 데이터(탁도, 염도 등)를 머신러닝으로 정밀하게 추정하여 복원**했습니다.
- **결과:** 305건의 100% 온전한 마스터 데이터셋 구축 성공.

### 3-3. CSO(합류식 하수관거 월류수) 플래그 생성
- `CSO_Flag`: 하수처리장 방류량이 평소(예: 450,000톤)를 초과하면서 동시에 3일 누적 강수량이 5.0mm 이상일 때 `1`로 활성화. 비가 와서 하수처리장이 감당하지 못하고 오폐수를 그대로 바다로 흘려보내는 상황을 수치화.

## 4. 모델링 기법: Dual-Output Regressor

다른 해수욕장(임랑, 일광)들이 Classifier(분류기)를 사용한 것과 달리, 다대포는 **연속적인 수치를 예측한 후 임계값을 씌우는 회귀-분류 하이브리드 방식**을 채택했습니다.

### 4-1. 모델 아키텍처
```
[입력: 15개 핵심 피처]
         │
         ▼
[ XGBoost Regressor (다중 출력) ]
         │
    ┌────┴────┐
    ▼         ▼
 log_ecoli  log_entero  (대장균, 장구균 농도를 동시 예측)
    │         │
    └────┬────┘
         ▼
[ 위험도 인덱스 산출 ] (예측값을 기준치 500, 100으로 나눈 비율의 최댓값)
         │
         ▼
[ 이중 임계값 분기 (Thresholding) ] ─→ 🟡주의(0.30) / 🔴위험(1.50)
```

### 4-2. 수동 피처 선택 (Domain Knowledge 적용)
- 다대포의 명확한 오염 메커니즘에 기반하여, RFE에 전적으로 의존하지 않고 15개의 핵심 피처를 수동 지정했습니다.
  - `precip_3d_sum_lag` (강수량)
  - `discharge_3d_sum_lag` (낙동강 하굿둑 방류량)
  - `sewage_discharge_3d_sum_lag` (하수처리장 방류량)
  - `CSO_Flag` (월류수 플래그)
  - `sensor_turbidity_max_1d_lag` (탁도 상승 → 흙탕물 유입)
  - `sensor_salinity_min_1d_lag` (염도 하락 → 민물 대량 유입)

> [!IMPORTANT]
> 다대포 모델은 "비가 오면 하굿둑 문이 열리고 흙탕물이 바다로 밀려온다"는 명확한 물리적 인과관계를 **수치 예측(Regression) 기반의 위험도 스코어**로 가장 잘 풀어낸 모델입니다.

## 5. 최종 모델 성능 지표

* **최종 ROC-AUC:** **0.946** (매우 우수한 성능)
* 하굿둑 방류량과 강수량이라는 강력한 오염 인자가 존재하기 때문에 0.9 이상의 높은 성능을 달성할 수 있었습니다.

### 5-1. 이중 임계값 경보 시스템 상세

| 단계 | 임계값 | Recall | 오탐(FP) | 용도 |
|---|---|---|---|---|
| 🟡 주의 | 0.308 | **89.1%** (41/46건) | 42건 | 관리자 선제 경보 (높은 예방력) |
| 🔴 위험 | 1.499 | **50.0%** (23/46건) | **단 1건** | 치명적 오염 통제 (매우 높은 정밀도) |

- **주의 단계:** 실제 오염 사고의 89%를 미리 잡아냅니다.
- **위험 단계:** 오탐(거짓 경보)이 305일 중 단 1건에 불과하여, 통제 발령 시 어민과 상인들의 반발을 최소화하면서 100% 확신을 가질 수 있습니다.

## 7. 주요 시사점 및 결론

1. **지리적 특성에 맞는 설계:** 개방형 해변인 일광이 해양(수온/기압/파고)에 지배받는다면, 다대포는 하구(Estuary)라는 특성 상 **방류량과 염도/탁도**에 절대적으로 지배받는 것을 데이터가 증명했습니다.
2. **머신러닝 기반 데이터 구출:** `IterativeImputer`를 통한 결측치 복원은 버려질 뻔한 280개의 검사 기록을 살려내어 0.946이라는 완벽에 가까운 AUC를 만드는 일등 공신이 되었습니다.
3. **Dual-Output 로직의 위력:** 대장균과 장구균을 각각 회귀로 예측한 후 최대 위험도를 구하는 방식은 오염의 '강도(Severity)'를 추정할 수 있게 해주어 매우 효과적이었습니다.
