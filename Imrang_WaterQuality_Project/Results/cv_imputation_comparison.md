# 임랑: CV 결측값 보정 방식 수정 후 성능 비교

동일한 master(93건, 초과 26건), 동일한 실행 환경과 5-fold 분할, RFE + SMOTE + Optuna 100회 설정으로 재학습했다.

| 항목 | 수정 전 | 수정 후 |
|---|---:|---:|
| AUC | 0.78702641 | 0.76521240 |
| 선택 변수 수 | 4 | 7 |
| 주의 임계값 | 0.24 | 0.31 |
| 주의 재현율 | 88.5% (23/26) | 92.3% (24/26) |
| 주의 오탐 | 28 | 35 |
| 위험 임계값 | 0.67 | 0.64 |
| 위험 재현율 | 57.7% (15/26) | 57.7% (15/26) |
| 위험 오탐 | 10 | 10 |

AUC 차이: -0.02181401. 임계값은 각 실행에서 다시 선택했으므로 동일 임계값 비교는 아니다.

## 수정 및 검증

- 원본 데이터를 CV로 먼저 분할하고 학습 폴드에만 보정기를 fit했다. 평가 폴드는 transform만 한다.
- 같은 분할을 사용하는 RFE 평가, Optuna 평가, 최종 CV는 학습 폴드별 보정 결과를 재사용한다.
- 평가값 교란 테스트에서 학습 폴드 보정 결과가 바뀌지 않음을 확인했다. 모든 값이 결측인 열의 유지와 평가 폴드의 전체 행 포함 여부도 확인했다.
- 저장된 예측의 날짜·정답·실측값이 master와 일치하며, 예측 파일에서 AUC를 재계산했다.
- 최종 저장 모델의 보정 및 분류 추론을 실행 확인했다.

## 남아 있는 평가 한계

전체 데이터 기반 RFE 변수 순위 결정(별도의 전체 데이터 보정 포함), 변수 선택·Optuna·최종 평가에 같은 분할을 재사용하는 구조 및 같은 예측값에서 임계값을 고르는 절차는 유지했다. 따라서 중첩 CV 또는 독립 테스트를 거친 일반화 성능이 아니다. AUC 변화는 보정 방식 수정 이후 변수 재선택·튜닝까지 포함한 파이프라인 결과다.

기존 results_Imrang.md, analysis_report_Imrang.md 및 그래프는 이번 실행으로 갱신하지 않은 과거 결과다. 기존 장구균 예측 열에 대장균 값을 복사하는 문제도 이번 범위에서 수정하지 않았다.

## 실행 환경

- scikit-learn 1.9.1, XGBoost 3.4.1
- imbalanced-learn 0.14.2, Optuna 5.0.0
